# Saura

Website for Saura, a sportswear brand. Plain HTML, CSS and vanilla JavaScript, no build step.

## Structure

```
index.html        Front page
css/styles.css    All styling. Brand colours and fonts are variables at the top (:root)
js/main.js        Header, mobile menu, scroll animations
```

## Run locally

```
php -S localhost:8080
```

Then open http://localhost:8080.
